# לנגה ❤️ — סיפור אינטראקטיבי

אתר Scrollytelling רומנטי בעברית (React + Vite + Framer Motion), מוכן לפריסה ב-Vercel.

## עריכת הסיפור ✏️

**כל התוכן נמצא בקובץ אחד:** [`src/data/story.js`](src/data/story.js)

- טקסטים שמתחילים ב"כאן אספר…" / "כאן יבוא…" הם **טקסטי דוגמה** — להחליף בסיפור האמיתי.
- `date` — תאריך קטן מעל כותרת פרק/רגע (ריק = לא מוצג).
- **תמונות:** לשים קבצים בתיקייה `public/images/` ולכתוב נתיב, למשל `image: '/images/moment-1.jpg'`.
  - רגעים (פרק 3): שדה `image` בכל רגע. בלי תמונה מוצג מספר מעוצב.
  - צילומי מסך של הודעות (פרק 2): `screenshots: ['/images/chat-1.jpg']` (עד 3).
- אפשר להוסיף/למחוק משפטים, בועות הודעות ורגעים — אורך הגלילה והאנימציות מחושבים אוטומטית.
- **פרטי הדייט:** `invitation.details` (תאריך, שעה, מקום, הערה). שדה ריק לא יוצג.
- **לקבל את התשובה שלה:** למלא `invitation.whatsappNumber` (למשל `972501234567`) — אחרי שהיא עונה יופיע כפתור ששולח לך את התשובה בוואטסאפ.

## הרצה מקומית

```bash
npm install
npm run dev
```

## פריסה ב-Vercel

1. להעלות את הריפו ל-GitHub.
2. ב-Vercel: **Add New → Project** ולבחור את הריפו. ההגדרות מזוהות אוטומטית (Vite, `npm run build`, תיקיית `dist`).
3. Deploy — ולשלוח לנגה את הקישור 💌

## איך זה בנוי

- `src/lib/schedule.js` — "ציר הזמן" של כל פרק: מתי כל משפט נכנס ויוצא, ביחידות של גובה מסך.
- `src/components/Scene.jsx` — פרק עם במה דביקה (sticky); `Beat` מופיע/נעלם לפי התקדמות הגלילה, `Words` חושף מילה אחר מילה.
- `src/components/Timeline.jsx` — ציר הזמן המואר, נקודות האור והלב בסוף.
- `src/components/Background.jsx`, `Particles.jsx` — גרדיאנטים, שינויי אווירה וחלקיקי אור.
- תמיכה ב"הפחתת תנועה" (Reduce Motion) של המכשיר: התנועה מוחלפת בהופעה רכה בלבד.
